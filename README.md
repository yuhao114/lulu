# 噜噜菜馆点餐系统

这是一个轻量级扫码点餐系统，包含顾客点餐页和商家后台。

## 功能

- 顾客登录、扫码桌号、菜单分类、搜索
- 规格、辣度、忌口、购物车、订单备注
- 下单后写入服务器数据库
- 商家后台登录：`/admin`
- 商家订单状态管理：已下单、待出餐、已完成
- 菜品管理、库存、售罄、改价、批量调价

## 运行

```bash
cd outputs/lulu-order
python3 app.py
```

打开：

- 顾客端：http://127.0.0.1:8099/
- 商家后台：http://127.0.0.1:8099/admin

## 部署

当前服务器部署路径：

- 应用：`/opt/lulu-order/app.py`
- 数据库：`/opt/lulu-order/lulu.db`
- systemd 服务：`lulu-order`
- Nginx 反向代理到：`127.0.0.1:8099`

数据库文件不提交到 GitHub。
